# 基础概念介绍

> 这都要写吗……？

笔者认为，扒谱指的是将音频中某些或全部乐器转换成易于编辑的格式（如 MuseScore 乐谱，MIDI，或 FL Studio 工程等等）。

## 扒谱中最常见的软件

### 打谱软件

即编辑各种乐器的乐谱（五线谱，吉他谱，鼓谱等等）的软件。一般支持鼠标输入，键盘MIDI输入等等。

- [MuseScore](https://musescore.org/zh-hans) 打谱软件，本篇文章的主要讨论对象。目前分 MuseScore 3 和 MuseScore 4 两个主要版本。MuseScore 4 支持直接导入 MuseScore 3 的文件，但反之则不支持。
- [Overture](https://sonicscores.com/overture/) 功能基本一致，需付费。
- [Sibelius](https://www.avid.com/sibelius) 功能基本一致，需付费。

笔者主要使用 MuseScore，因此下文均以 MuseScore 软件为例做介绍。
### MIDI预览软件

- [MidiEditor](https://midieditor.org/) 支持简单的 MIDI 预览与编辑功能。
- [Domino](https://takabosoft.com/domino) 与 MidiEditor 功能差不多，但只有日文版。

更多软件见附录。

下文中，若无特殊说明，扒谱过程均以音频文件（如 .mp3, .wav, .mp4 等等）为开始，以 MuseScore 乐谱（即 .mscz 格式）为最终的目标。

# 准备工作

你首先得知道要扒的歌的曲名。如果只能回想起或临时听到一小段旋律，想要知道曲名的话，可以试试听歌识曲网站。网易云、QQ音乐等国内APP对华语流行的支持度较好；Spotify 等外国流媒体平台则对欧美歌曲效果较好。网页端听歌识曲工具例如 [AHA Music](https://aha-music.com/zh)，[Shazam](https://www.shazam.com/) 等等也很好用。

## 获得音频

最简单的一部分。

先在网上搜一下，各类云音乐平台大概率会有。专辑可以去 [Bandcamp](http://bandcamp.com/) 上找一下。可以配合 [猫抓](https://github.com/xifangczy/cat-catch) 浏览器插件实现资源的下载。

如果你不太懂如何下载，也有一个并不优雅的方法：可以一边播放一边录屏，也能获得歌曲的音频，虽然音质会差一些。

# 开始扒谱

获得音频之后，便可以着手进行扒谱工作了。先确定歌曲的分类：流行还是古典？纯钢琴还是多乐器？虽然每类歌曲有不同的优化方法，但大体上都可以分为如下几步。

## 判断基本信息

这里的基本信息包括以下几种：
- 标题/副标题
- 曲作者/词作者
- 乐器种类
- 速度
- 调性
- 拍号
- 小节数

标题与作者通常在一开始即可确定好，乐器种类听几遍歌也很容易能确定下来。

歌曲的速度一般以 Beats per minute (BPM) 来衡量，表示一分钟内歌曲的节拍数，一般取整。（特殊情况例如 *FREEDOM DiVE↓* 的 BPM222.22 等等，可以查询得到）

测量BPM的方法大概有如下几种：
- 敲击测速，直到BPM稳定即可基本确定。根据经验，误差大约±5。往往需要软件辅助，例如：
	- 许多节拍器应用程序会附带这种功能，如 移动设备上的的 [‎Pulse](https://apps.apple.com/cn/app/pulse-metronome-tap-tempo/id1097323003)，Windows 下的 BPMCount.exe
	- DAW 中也常常会附带，在 FL Studio 右键左上角的速度框，敲击，即可打开敲击测速器
	- osu! 中的地图编辑器也有类似功能
- 使用上述轨道分离的网站自动确定，比较方便，误差大约±1。
- 使用应用程序自动确定，如 [MixMeister BPM Analyzer](https://www.mixmeister.com/) 等，也很方便，误差大约±0.5。注意一下使用 MixMeister BPM Analyzer 会将 BPM 自动写入歌曲文件元信息中，建议复制一份副本导入软件中进行测量；测量完成后删除副本文件即可。
- 将音频放入音频编辑器（如 Audacity，WaveTone 等），设置 BPM 与延迟直到格线与歌曲的重音精确对齐。适用于精确测定 BPM，误差大约 ±0.1。

注意有些歌曲可能会变速，即在中途改变BPM。如果使用软件进行自动测量，可以使用音频分割工具在歌曲的变速处切开，分别放到软件中即可。

如果是音游曲，可以上 osu! 网站搜索，一般来说可以看到较为准确的速度与变速信息。

生演奏（人手演奏）的BPM一般不是恒定的，最多会偏差±5。扒谱不要求与原曲完全重合，挑选最平均 BPM 取整即可。

调性即几个升降号，若能听出来明确的全音阶，即可把“哆”音的绝对音作为大调的首音，以此确定调性。拍号可以寻找歌曲的节奏与重音规律，找一些视唱练耳教程可能会辅助你增强辨认调性与拍号的能力。

速度、调性、拍号等信息也可以使用下面即将要提到的在线网站，在轨道分离时顺便确定下来。

确定好以上的歌曲基本信息后，就可以在 MuseScore 中创建新文件并输入了。

## 轨道分离

大多数的歌曲由两种及以上的乐器组成。常见的乐器比如：
- 人声。不要再质疑人声是不是乐器了，“丝不如竹，竹不如肉”（《晋书·孟嘉传》），弦乐不如管乐动人，管乐又比不上人声，人声是最高级、最自然的“乐器”。
	- 多轨的人声一般叫合唱，SATB 就是 Soprano Alto Tenor Bass，女高音 女低音 男高音 男低音。合唱一般配一个钢琴作为伴奏。
- 流行四大件：钢琴，吉他，鼓，贝斯~~（没事贝斯听不见不用扒）~~
	- 钢琴有延音踏板，有时候这会对钢琴扒谱造成不小的困难。
	- 吉他分木吉他和电吉他。二者音色有很大的不同，注意区分。
	- 鼓有单独的鼓谱，MIDI也设置了单独的轨道与音高-音色对应表（[GM音色库打击乐列表](https://wwww.lnc.edu.cn/dp/sec/art/zysz/yyby/jxcg/12202.html)）。
	- 贝斯虽然从频段上是低声部，但从功能作用上它串联了节奏与和声，它是律动与旋律的粘合剂。不能不扒。
- 弦乐：小/中/大/低音提琴（组）等等
- 合成器。现代电子乐中你说不清楚是啥乐器的一般都是各种合成器。
- 还有更多……但太复杂的笔者也不会，所以在这篇文章里大概不会出现。

轨道分离不是必须的。如果你大脑装了傅里叶变换插件，可以自动忽略其他音色的干扰，那么是否分离其实无所谓，对着原曲直接干就行。
如果你和笔者一样，没有绝对音感也没有插件，那么你很可能需要轨道分离的帮助。

在线网站：
- [AudioJam](https://audiojam.app/zh-CN/studio/) 完全免费的乐器伴奏分离，和弦音调分析网站。专为扒谱设计，强推。
- [团子AI](https://tuanziai.com/) 比较不错的音频AI工具集合网站。常用的包括 [任意乐器分离](https://tuanziai.com/stem-separator)，[提取伴奏人声](https://tuanziai.com/vocal-remover) 等等。缺点是需要付费，单曲6元/首。
- [乐器分离器](https://vocalremover.org/zh/splitter-ai) 与 [vocalremover](https://vocalremover.org/zh/) 去人声。优点是完全免费，效果也不错，支持导出为无损 WAV 格式方便进一步处理。之前笔者用的就是这个。

本地工具：
- [UVR](https://ultimatevocalremover.com/) 本地运行效果不错，支持人声分离与音轨分离（适合批量去人声，在TTS模型训练中很有用）
- Python Spleeter Library
- 许多DAW也自带音轨分离和人声分离功能，如果有的话可以试试。

分离完后你应该会拿到几个音频，可能会有钢琴，鼓，贝斯，弦乐，人声，其他等等。笔者建议从钢琴开始。

# 钢琴扒谱

## 总流程

1. 确定歌曲的和弦进行；
2. 按4小节或8小节确定高低声部的每个音，先高后低；
3. 复制和声部（低声部），铺满至16小节或32小节，同时注意最后数小节的和弦变化；
4. 写出16小节旋律线；
5. 同时播放原音频与乐谱，注意听不同之处以检查。
6. 重复以上流程至歌曲结束。若歌曲有反复部分，复制并在此基础上修改可大大减少工作量。
7. 加入力度记号、表情记号与圆滑线（可选）。
8. 根据音频或自动生成的MIDI文件加入踏板，最后检查混音与音量大小。

以上 1-5 步可通过下面的自动工具完成大部分，以作为参考来减少工作量。

## 自动工具扒谱

笔者参考知乎上的一篇文章进行了各类自动扒谱工具测试：[测试了9款钢琴音频转五线谱网站（软件） - 知乎](https://zhuanlan.zhihu.com/p/1972670710125200402)。下面介绍一些笔者用过且较为好用的网站与程序。
### Piano2Notes

[Piano2Notes](https://piano2notes.klang.io/) 实测下来最好用的钢琴转乐谱网站。

付费，可免费预览上传音频的前 30s 且无数量限制，免费版只能导出下载 PDF 文件；单独购买整首乐曲需要每首 28r。

可以使用如下的 Powershell 脚本将给定的音频切割成长度为 30s，间隔为 25s 的小段，方便在网站上挨个免费进行处理。需要安装 ffprobe 工具并放入环境变量。

```powershell
$in="input.wav"
$o="chunks"
$len=30
$step=25
mkdir $o -Force | Out-Null
$dur=[double](ffprobe -v error -show_entries format=duration -of default=nk=1:nw=1 $in)
$s=0; $i=1
while($s -lt $dur){
  $t=[math]::Min($len,$dur-$s)
  ffmpeg -y -hide_banner -loglevel error -ss $s -i $in -t $t -acodec pcm_s16le (Join-Path $o ("part_{0}_{1}.wav" -f $i, $s))
  $s+=$step; $i++
}
```

导出 PDF 下载后可参见下面的 PDF 转可编辑乐谱章节，进行进一步操作与合并。

### capella audio2score

[capella audio2score](https://www.capella-software.com/index.cfm/us/products/capella-audio2score-pro/info-capella-audio2score-pro/) 比较好用的软件。破解后免费，可直接导出 .musicxml 文件，方便直接导入至 MuseScore 中进行修改。

导入音频，选择 Piano only，等待乐谱生成即可。注意调整 Volume threshold 与 Details 两参数以获得更优秀的效果。依笔者经验来看，将 Volume threshold 与 Details 均略大一些，实际效果会更好。

### piano_transcription

将纯钢琴音乐转换为带踏板的 MIDI 文件。

[bytedance/piano_transcription](https://github.com/bytedance/piano_transcription) 命令行工具
[azuwis/pianotrans](https://github.com/azuwis/pianotrans) 建议使用带图形界面版本。
点击页面右侧 [Release Release v1.0 · azuwis/pianotrans](https://github.com/azuwis/pianotrans/releases/tag/v1.0) 下载整合包。

此法生成的 MIDI 文件没有测定 BPM 且包含了延音踏板等效果，因此将生成的 MIDI 文件直接导入 MuseScore 中给出的乐谱较为混乱，不好修改。可以在导入之前参考 [AI扒谱 - Piano_transcription_inference - 知乎](https://zhuanlan.zhihu.com/p/658722388) 对 MIDI 文件进行变速与修缮。但实际体验下来，生成的MIDI文件变速与修缮过程较为繁琐。

因为此法准确率最高，笔者推荐将 MIDI 导入 MIDI 预览器（如 MidiEditor 或 FL Studio）中，与 Piano2Notes 生成的清晰乐谱做对照补充。

## 手动扒谱与对照确认

通过上方自动扒谱生成的乐谱准确率往往不会很高；也有很多人喜欢传统派扒谱，即不依赖AI工具，通过人耳或基础频谱工具进行听辨分析。下面介绍一下笔者的传统扒谱流程。

将音频慢放，使用 [Sonic Visualiser](https://sonicvisualiser.org/download.html)（免费，建议使用），WaveTone 或 [Transcribe!](https://www.seventhstring.com/xscribe/download.html) 进行慢放听音与频谱图精确分析。下面以 WaveTone 工具为例。

使用 WaveTone，将音频拖拽进去，打开BPM网格线，设置合适的BPM；在上方中间处调整合适的感受音量（灵敏度与对比度）以便分析。通常适当调大一些。

界面显示频谱图如下：

![[Pasted image 20260706133651.png]]

红条代表可能的音与泛音。泛音列中包含三个泛音，分别比本音高八度、八度加五度、两个八度。例如本音是 C5，那么它的泛音列是 C6，G6，C7。第一个（高八度）的泛音较强；后两个较弱，可通过适当调大对比度（约60）来消除。

建好 MuseScore 文件后就可以开始写音符了。笔者习惯通过人耳先确定没每小节的和弦进行，依照频谱图的结果确定转位，写入乐谱中。重复直到一个和弦进行完毕，开始写旋律线。
频谱图可用来确定旋律线中多重音符的较低音，具体是三度还是五度等。复杂节奏型可以参考频谱图中的小节线来确定。
依此写出一段内的所有音符即可。检查过程可以通过慢速（如将音乐设置为0.5倍速，MuseScore 中 BPM 减半）同时播放音乐与乐谱，调整二者音量相同，注意听有没有音符的不同来实现。

也可以将 piano_transcription 生成的 MIDI 文件导入至 MIDI 预览器，对频谱图进行对照补充。

笔者总结出一些扒谱流程与技巧供参考：
- 先和声再旋律，先左手再右手；
- 善用复制粘贴功能，遇到重复的段落先复制粘贴再检查；
- 善用高低八度谱号；
- 整体写完后再补力度记号、表情记号与圆滑线；
- 左手无名指放在键盘的 `4`，中指放在 `5`，食指放在 `6` 方便切换音符时值；大拇指放在 `N` 与 `.` 以切换音符输入模式和输入附点。

## MIDI 导入注意事项

虽然 MuseScore 支持直接导入 MIDI 文件，但对于有些尤其是钢琴文件，直接导入至 MuseScore 后会发生包括但不限于以下问题（实例如下）：
- BPM 不对（如不是乐曲而是默认的 120）
- 乐谱很乱（延音线，多声部等，通常是踏板问题）
- 多连音识别错误
- 奏法记号多或少
- 将断奏号识别为十六分音、三十二分音等等
- 力度错误，某些音符音量过大或过小
- ……
![[Pasted image 20260707133908.png]]
![[Pasted image 20260707133951.png]]

可以在 MuseScore 中修改 MIDI 导入设置，如降低最大量化与最多声部数、减少识别的连音、取消勾选真人演奏等等。

对力度错误的问题，导入转为乐谱后，如果有某些音符音量过大或过小（不能通过调整力度符号修改），可以右键任意一个音符，选择-全部相似元素，`F8` 打开元素检视器，找到音符-调音，全部重置即可。

## PDF 或图片转可编辑乐谱

有时一些网站或B站视频仅提供乐谱的 PDF 文件或图片，想要把不可编辑的 PDF 转换为可编辑的乐谱文件，最简单的办法可以手敲。手敲技巧与扒谱技巧基本相似，但也有些不同：笔者更推荐先旋律再和声，先右手再左手的输入顺序。

手敲太累了，可以使用自动识别软件以简化工作流程。笔者较为推荐以下两款自动识别软件：[capella-scan](https://www.capella-software.com/index.cfm/us/products/capella-scan/info-capella-scan/) 与 [PDFtoMusic Pro](https://myriad-online.com/en/products/pdftomusicpro.htm)。前者识别准确率较高且便于在网上找到破解版，因此更为推荐前者。使用也很方便，支持导出为 .musicxml，无损导入 MuseScore 即可。但不建议在导入的 musicxml 文件中直接修改，可以新建 MuseScore 文件再粘贴进去。如果有识别出来多余的文本或和弦符号，右键任意一个文本，选择-全部相似元素，`Delete` 删除即可。

粘贴并手动检查完毕后，`Ctrl+A` 选择所有音符，点格式-重置文本样式优先级、重置符号、重置形状与位置，来清除自动识别出的一些位置信息，恢复默认。

# 收尾工作

以上流程走完一遍，你的谱大概就扒出来了。如果想把乐谱变成可以听的音频文件或可以看的视频文件，还需要进行下面的收尾工作。

## 音源

音源指一系列乐器的音频，将乐谱渲染为可以听的音频，其中乐器的音色就是由音源提供的。常见的音源格式有 .sfz, .sf2, .sf3 等等。

音源中常见的乐器音色主要有钢琴，提琴（弦乐组），鼓，各类合成器……
MuseScore 3 和 MuseScore 4 自带的音源包含了几乎所有乐器，质量也不错，可用于音乐与视频渲染。

## 视频渲染与导出

B站里常见音乐视频种类大概有五线谱预览和钢琴渲染两种。

### 五线谱渲染

传统方法是使用录屏软件录屏，打开录屏软件，MuseScore 中使用 Ctrl+U 全屏，使用录屏软件录下 MuseScore 播放乐谱即可。

MuseScore 4 新版本自带直接导出五线谱预览，支持按页面或按行渲染功能。美中不足的是视频最后会带一小段Made with MuseScore Studio 的视频水印。可以使用视频剪辑软件很轻易地去掉。

## 钢琴渲染

可以使用下列软件获得较好的钢琴渲染体验：

- [Embers](https://embers.app/) 可免费预览，但免费版不能调整特效，且有水印；使用内置的导出生成视频需要在 Patreon 赞助。优点是特效较为美观，自带的钢琴 Yamaha Grand-v2.1.sf2 音源质量较好。缺点是导出视频需要付费，且默认仅支持钢琴一种乐器。
- [Synthesia](https://www.synthesiagame.com/) 笔者没用过。破解可在 [Pigeon114514](https://miditrail.ysepan.com/) 上找到。
- [MIDITrail](https://yknk.org/miditrail/en/download/) 较为全面的 MIDI 3D 渲染播放器。B站上有不少东方自编曲预览是用本软件录制的。优点是完全免费，使用方便，支持的乐器种类很全。缺点是依靠 Windows 波表来播放，音源质量较差；少部分情况下电脑缺少驱动就会播放不了。没有自带渲染视频功能，需要录屏。
- [Zenith](https://github.com/arduano/Zenith-MIDI) 专门用于渲染黑乐谱。没有自带的音频渲染功能，但可以通过 MuseScore 导出音频并导入软件中，直接渲染成视频。目前笔者在 B 站上传的几个渲染视频都是用的这个软件。
## 文件上传

笔者提倡所有人将乐谱开源，非常不建议将乐谱收费卖出的行为。好的音乐应该发出来让大家自由欣赏，自由编辑，而不是来谋取利益。
笔者所有的乐谱均开源至蓝奏云网盘，可在每个视频简介中找到对应的链接。在这里希望所有B站音乐/钢琴区UP主都可以将乐谱免费提供出来，让更多的人和体会自由欣赏修改音乐的快乐。

	- 但乐谱文件也没那么大啊，反正肯定不到100MB。把你的 .mscz，.mid 文件打成 .zip 压缩包即可上传。
	- 笔者推荐所有人都来用蓝奏云。
- [移动云盘](https://yun.139.com/) 完全免费，下载不限速。也很推荐使用。

不推荐使用：

- [123云盘](https://user.123pan.cn/) 并非不限速。

耻辱榜：

	- 嗯，PanDownload 现在半死不活的。笔者不想充会员，且并不想要享受 10KB/s 的下载速度。
