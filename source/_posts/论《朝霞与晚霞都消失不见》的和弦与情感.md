# 走向分析

尝试逐段进行和弦走向的分析，并结合歌词理解其情感。因为笔者的日语水平堪忧，且 passthem 的中文填词既符合原意又水平高超，所以下文中笔者用中文填词代替日文原词进行分析。

整体上，歌曲反复使用E♭大调与C小调的相对调关系，在E♭大调与C小调间切换，大量使用 EbM7 ↔ Cm7：
+ Ebm7: Eb - G - Bb - D
+ Cm7: C - Eb - G - Bb

两者有E♭、G、B♭三个共同音，而根音C与E♭之间的转换非常平滑，因此可以在大调情感与小调情感间丝滑切换，而这是歌曲表达情感所必要的。

同时，E♭大调与C小调同样具有如此特性：
+ E♭大调：E♭、F、G、A♭、B♭、C、D
+ C小调：C、D、E♭、F、G、A♭、B♭

只需要改变旋律的功能重心，就可以在大调和小调之间切换。

在E♭大调中，主要自然音级和弦为

| 级数   | 和弦    | 功能            |
| ---- | ----- | ------------- |
| I    | EbM7  | 主和弦           |
| ii   | Fm7   | 下属方向、属和弦前置    |
| iii  | Gm7   | 中介和弦          |
| IV   | AbM7  | 下属和弦          |
| V    | Bb7   | 属和弦           |
| vi   | Cm7   | 关系小调、相对阴暗的中心  |
| viiø | Dm7b5 | 通常通向Gm或作为经过和弦 |

但这首歌经常把 G7、Gaug7 作为C小调的属和弦使用：如 Dm7b5 - G7/Gaug7 - Cm7 (小调中的 iiø7 - V7 - i)。

**Gaug7**（增五属）反复出现，作为全曲的情绪锚点，主要功能为通向 Cm (V7#5 → i)。增五音D♯与C之间形成强烈的半音张力，G到C又构成属到主的五度关系。相比普通G7，Gaug7更不稳定，更具有悲伤色彩。

歌曲中有很多出彩的色彩和弦，第一遍出现时在下面会用粗体标注，并着重分析。

## 前奏

> Fm7 - Bb7 - | Gm7 - Cm7 **Eb9** | AbM7 - Bb7 - | EbM7 - Dm7b5 **Gaug7**  
> ii - V - | iii - vi | IV - V - | I - iiø V7#5/vi  

Fm7 - Bb7 - Gm7 - Cm7 (IIm7 - V7 - IIIm7 - VIm7)：流行乐 2-5-3-6 进行，在 Cm7 后面紧跟了一个 Eb9 (I9)。**Eb9** 作为一个次属和弦（V7/IV），打破了原有的稳定，强烈地倾向并解决到下一小节的 AbM7 (IV)。

AbM7 - Bb7 - EbM7 (IV - V - I)：大调 4-5-1 解决，带来短暂的光明感。

Dm7b5 - **Gaug7** (VIIm7b5 - IIIaug7)：切换到C小调的 2-5 进行。本来到 Dm7b5 就够了，已经很倾向于解决，但是增加了 **Gaug7**，使结尾更加富有张力与扩张感（在歌曲本身中可能听不太出来）。Gaug7 在后面也反复出现，主要功能为通向 Cm。增五音D♯与C之间形成强烈的半音张力，G到C又构成属到主的五度关系。相比普通G7，Gaug7更不稳定，更具有悲伤色彩。

**Cm7** (VIm7) 起手，避开了大调主和弦（EbM7），从关系小调主和弦开始，奠定了歌曲暗沉、寒冷的基调，对应歌词的“彷徨”“迷路”等主题。

第一遍结尾的 Dm7b5 - Gaug7 与前奏一样，使用C小调的 2-5，引出第二遍。

第二遍结尾的 EbM7 - **Eb7**，此时没有再用 Gaug7，转而使用了 **Eb7**，变成了引向四级 (AbM7) 的次属和弦，将情绪自然地推进到B段。到那——

AbM7 - **Abm6** (IVM7 - IVm6)：下属小和弦，大七变小六，平行小调借用，将 E♭ 大调的明亮色彩染暗。由于根音保持不动，这种变化很自然，但同时有着“心伤早已结冰”的冲击力。

Gm7 - C9 - Fm7，3-6-2 进行，C9 作为次属和弦连接到 Fm7。

Fm7 - Gaug7 - Cm7，Gaug7 再次出现，把 Fm7 强行拉回 Cm7。

Cm7 - C7 - **Cb** (VIm7 - VI7 - bVI)：极其惊艳的离调借用，C7 本该解决到 Fm7，但它却进行了一次阻碍解决，到了 **Cb** 上。Cb 是从小调借用来的降六级和弦，色彩极其黑暗与冰冷。

**Cb**(B) - **Cbdim7**(Bdim7) - Bbm7 半音下行，通过减七和弦中的共同音和半音移动，把两个相距半音的根音连接起来。听起来有一种下坠感，契合歌词的“仿佛要堕入那/霜冻的深海里”。同时注意到减七和弦本身具有对称结构，因此很适合做过渡。

Bbm7 - Eb (Vm7 - I) 是 次属的 2-5 进行，本该解决到 AbM7，但后面则是一小节 **Dm7** - 一小节 **Gaug7**。并没有解决到 AbM7 上，而是突兀的停在了 **Dm7** (VIIm7) 上，随后变成 **Gaug7**，持续了两小节，对应着歌词的“我的心却无比地平静”，憋气要憋炸了，等待着C段的爆发。

B段结尾的 Gaug7 理论上应该解决到 Cm7，但副歌第一个却是 **Fm7** (IIm7)，这种错位感进入梦境了，承接下方的 Fm7 - G7 - Cm7，C小调的 4-5-1 进行。

Cm7 - Cbm7 - Bbm7 - Eb9 则是又一个半音下行，根音 C - B - Bb 下行，Cbm7 是一个经过和弦，如同坠落到“灰暗之地”的过程，而 Bbm7 - Eb9 则形成了一个通往四级（AbM7）的 2-5 进行。

AbM7 - **G9** - Cm7 是大调的 4-3-6 进行（小调 6-5-1），句中的 **G9** 和句末的 **Eb9** 将原本稳定的大三和弦改成属九，使歌曲产生一种迫切的需要解决感，解决到 Cm7(vi) 和 Fm7(ii) 上面。

**Dm7b5** - **Gaug7** - Cm7 - Eb9：使用 **Dm7b5** 半减七引出 **Gaug7** 增和弦，再回到小调主和弦，最后用 Eb9 再次将乐句推向 AbM7，形成循环。

段尾 Eb - **C7** 中 **C7** (V7/II) 作为回转和弦，将进行重新拉回开头的 Fm7，让歌曲如同“朝霞与晚霞都消失不见”一样无限循环。

## 反复

> AbM7 - Bb7 - | EbM7 - **Dm7b5** **Gaug7**  

> 我的心悲寂　独自成伤暗自啜泣  
> 乍暖还寒惨惨戚戚心恸难将息  
> 朝霞与晚霞　悄然淡出我的记忆

按流行音乐习惯而言，最后通常会以 4-5-1 解决在 EbM7 上。但结尾却停在了 **Gaug7** 属增七上，这是一个极其不稳定的悬挂和弦，没有任何解决，在往复之间被抹去踪迹。

# 大调还是小调？

在以上的分析中，笔者不加区分的对大小调的和弦走向进行混用。事实上，《自由派音乐理论》中也有类似的说法，在现代流行音乐中，大调小调并不需要加以过多的区分。见 [大调与小调的区别](https://music-theory.aizcutei.com/post/%E5%92%8C%E5%BC%A6%E7%AF%87/2-%E5%A4%A7%E8%B0%83%E4%B8%8E%E5%B0%8F%E8%B0%83%E7%9A%84%E5%8C%BA%E5%88%AB)。因此，对于寻求明暗中间区域的流行音乐来说，可以给出调性的“一元论”或“多元论”：

> 这个想法是假设一个中间或重叠的调的状态，其中“二元论”的大调和小调基本上是连接在一起的，但根据每个时刻的旋律线和和弦，在它们之间摇摆。

《朝霞与晚霞都消失不见》就是一个极好的例子。如果是纯粹的 Eb 大调，歌曲会显得过于阳光和希望；如果是纯粹的 C 小调，又会显得过于古典式的悲剧和彻底的绝望。但这首歌的精髓恰恰在于这种“摇摆不定”，这种调性的叠加态正对应着歌词中“我彷徨在/某座城市里/不知道路何处寻”与歌曲的总体情感。

# 关于填词

我们可以注意到，原曲的发布时间为 [*2020年4月28日*](https://zh.wikipedia.org/wiki/2019%E5%86%A0%E7%8A%B6%E7%97%85%E6%AF%92%E7%97%85%E7%96%AB%E6%83%85)。在B站视频下的评论区，有很多观看者发表了或是关于歌曲本身，或是关于中文填词的评论。笔者在此摘取其中一个评论为例，表现了“幽闭恐惧”与“抑郁解离”等症状：

> 你的歌词写的太好......或者说太危险了，里面充满了关于“孤独”的暗示。  
> 我之前在评论区里发布了（出于指导目的的实验性）精神卫生敬告。因为我在品鉴这首mad的时候刚好是光线昏暗、温度较凉且空无一人的空教室里，再加上这首歌曲的强调和暗示使我有了非常负面的心理反应。  
> 发布后，虽然我觉得自己的敬告郑重过头，但还是打算再观望一会，但是随着时间推移，确实出现了和我一样出现心理反应的观众。  
> 这使我认为自己的敬告是有意义的，也许可以建立一套对于鉴赏试听作品具有安全指导作用的贴士系统，它应当站在同龄人的视角而不是大家长的视角，它也和视听音像作品分级并没有关联......我并不是相关从业者，也尚且没有正式的从业资质，我对抑郁症的认知都是基于现在对公众的科普教育，所以目前还有很多术语不懂，知识也比较匮乏......  
> 总而言之，请尽情挥洒才情，需要、也总有一天会有人帮创作者在这部分问题上分忧的

这或许也可以在侧面证明，音乐（本文中以和弦走向为例）与歌词是密不可分的整体；而二者结合起来所表达的情感同样也证明了，无论是原曲还是填词，这首歌曲都有着极强的情绪感染力。
