# 使用指南

本列表为 LLM 搜集的 MIDI 与乐谱分享站的整理，并没有做过多人为筛选与可用性检测，一句话简介也多为 LLM 生成。

请善用科学上网。如遇死链，请善用 archive.org 与 Wayback Machine。

排序方式大概为：从能直接找到 MIDI 的知名度较高的大站，到适合考古的冷门小众站点。建议查找顺序从上到下。

# MIDI 数据集

## 数据集索引与符号音乐语料库

* [MusPy](https://github.com/salu133445/muspy) 符号音乐数据集索引，集中整理 Lakh、MAESTRO、MusicNet、NES、Nottingham、Wikifonia、Essen、EMOPIA 等数据集。
* [Lakh MIDI Dataset](https://colinraffel.com/projects/lmd/) 大型 MIDI 数据集；另有 [clean_midi 子集直链](http://hog.ee.columbia.edu/craffel/lmd/clean_midi.tar.gz)。
* [Lakh MIDI — GitHub / MuseNet](https://github.com/asigalov61/LAKH-MuseNet-MIDI-Dataset) Lakh MIDI 的 GitHub 整理版本。
* [MAESTRO Dataset](https://magenta.tensorflow.org/datasets/maestro) 钢琴演奏音频与 MIDI 对齐数据集；提供 [MIDI-only v3.0.0 直链](https://storage.googleapis.com/magentadata/datasets/maestro/v3.0.0/maestro-v3.0.0-midi.zip)。
* [MusicNet](https://homes.cs.washington.edu/~thickstn/musicnet.html) 古典音乐录音、MIDI 与 note-level 标注。
* [Wikifonia Lead Sheet Dataset](https://github.com/wayne391/wikifonia) Lead sheet、旋律与和弦数据。
* [Essen Folk Song Database](https://kern.humdrum.org/) 民歌旋律数据集。
* [Nottingham Database](https://ifdo.ca/~seymour/nottingham/nottingham.html) 民歌旋律与和弦数据集。
* [JSB Chorales](https://www.music21.org/music21docs/aboutReferenceCorpus.html) 巴赫四声部圣咏语料库，可通过 music21 使用。
* [EMOPIA](https://annahung31.github.io/EMOPIA/) 带情绪标注的多轨符号音乐数据集。
* [music21 Corpus](https://www.music21.org/) music21 附带的乐谱与符号音乐语料库。

## 可直接下载的 MIDI 数据集

* [Groove MIDI Dataset v1.0.0（MIDI-only）](https://magenta.withgoogle.com/datasets/groove) 鼓组演奏 MIDI；提供 [MIDI-only 直链](https://storage.googleapis.com/magentadata/datasets/groove/groove-v1.0.0-midionly.zip)。
* [POP909 Dataset](https://github.com/music-x-lab/POP909-Dataset) 中文流行音乐的 MIDI 与符号编曲数据；提供 [GitHub ZIP 直链](https://codeload.github.com/music-x-lab/POP909-Dataset/zip/refs/heads/master)。
* [ASAP Dataset](https://github.com/fosfrancesco/asap-dataset) 钢琴演奏音频、MIDI 与演奏标注；提供 [GitHub ZIP 直链](https://codeload.github.com/fosfrancesco/asap-dataset/zip/refs/heads/master)。
* [PiJAMA Hawthorne MIDI](https://zenodo.org/records/8354955) PiJAMA 项目的 Hawthorne MIDI 子集；提供 [ZIP 直链](https://zenodo.org/api/records/8354955/files/midi_hawthorne.zip/content)。
* [PiJAMA Kong MIDI](https://zenodo.org/records/8354955) PiJAMA 项目的 Kong MIDI 子集；提供 [ZIP 直链](https://zenodo.org/api/records/8354955/files/midi_kong.zip/content)。
* [ADL Piano MIDI](https://github.com/lucasnfe/adl-piano-midi) 钢琴 MIDI 数据集；提供 [ZIP 直链](https://raw.githubusercontent.com/lucasnfe/adl-piano-midi/master/midi/adl-piano-midi.zip)。
* [VGMIDI](https://github.com/lucasnfe/vgmidi) 电子游戏音乐 MIDI 数据集；提供 [GitHub ZIP 直链](https://codeload.github.com/lucasnfe/vgmidi/zip/refs/heads/master)。

* [MusicBrainz Full Dump](https://metabrainz.org/datasets/postgres-dumps) MusicBrainz 完整 PostgreSQL 数据库转储；参见 [下载说明](https://musicbrainz.org/doc/MusicBrainz_Database/Download)。
* [Discogs Monthly Data Dump](https://data.discogs.com/) Discogs 每月音乐元数据转储。
* [FMA-Large / FMA-Full](https://github.com/mdeff/fma) Free Music Archive 音频数据集；另有 [Kaggle 镜像](https://www.kaggle.com/datasets/brunosette/fma-large)。
* [Stack Exchange Music Q&A](https://archive.org/download/stackexchange) Music Stack Exchange 数据转储，提供 [7z 直链](https://archive.org/download/stackexchange/music.stackexchange.com.7z)。
* [Stack Exchange Signal Processing](https://archive.org/download/stackexchange) Signal Processing Stack Exchange 数据转储，提供 [7z 直链](https://archive.org/download/stackexchange/dsp.stackexchange.com.7z)。
* [Stack Exchange Video Production / AVP](https://archive.org/download/stackexchange) Video Production Stack Exchange 数据转储，提供 [7z 直链](https://archive.org/download/stackexchange/avp.stackexchange.com.7z)。
* [FineWeb-Edu sample-100BT](https://huggingface.co/datasets/HuggingFaceFW/fineweb-edu/tree/main/sample/100BT) 教育文本数据集样本，与 MIDI 无直接关系，单独保留作通用数据集索引。
* [MTG-Jamendo Dataset](https://mtg.github.io/mtg-jamendo-dataset/) 音频与音乐标签数据集；另有 [Zenodo 元数据页](https://zenodo.org/records/3826813)。
* [JamendoMaxCaps Captions](https://huggingface.co/datasets/amaai-lab/JamendoMaxCaps) Jamendo 音频字幕/描述数据集；项目页见 [GitHub](https://github.com/AMAAI-Lab/JamendoMaxCaps)。
* [Groove MIDI Dataset / E-GMD](https://magenta.withgoogle.com/datasets/e-gmd) Groove 的扩展版本，包含更大规模的鼓组演奏数据。
* [ChoralSynth](https://github.com/MTG/ChoralSynth) 合唱音频与符号音乐数据集；另有 [Zenodo 页面](https://zenodo.org/records/10137596)。
* [DEAM Emotional Music Dataset](https://cvml.unige.ch/databases/DEAM/) 带情绪标注的音乐数据集；另有 [Kaggle 镜像](https://www.kaggle.com/datasets/imsparsh/deam-mediaeval-dataset-emotional-analysis-in-music)。
* [Million Song Dataset](https://millionsongdataset.com/pages/getting-dataset/) 大规模音频特征与元数据数据集，参见 [项目主页](https://millionsongdataset.com/)。
